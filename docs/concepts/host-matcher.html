Host Matcher

HostMatcher handles host overrides from hosts files. It supports exact, prefix, suffix, and substring wildcard patterns.

Examples

Suffix wildcard

10.0.0.1 *.example.com

Prefix wildcard

10.0.0.2 example.*

Substring wildcard

10.0.0.3 *ads*

Specificity Rule

Longest core wins.


10.0.0.10 *.example.com
10.0.0.20 *ample.com
10.0.0.30 *ple.com

Query: foo.example.com → 10.0.0.10

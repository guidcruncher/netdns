Rule Engine

The RuleEngine determines which upstream resolver should handle a DNS query. It supports exact, prefix, suffix, substring, wildcard, and regex rules.

Example Rule


{
  "Name": "cloudflare",
  "Address": "1.1.1.1",
  "Port": 53,
  "Rule": "*.example.com"
}

Matching Order

  1. Hosts overrides
  2. Exact rules
  3. Suffix rules
  4. Prefix rules
  5. Wildcard substring rules
  6. Regex rules
  7. Fallback resolvers

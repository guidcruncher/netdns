Blocklists

DnsForwarder supports blocklists from any source implementing IBlocklistSource. Blocklists can contain wildcard patterns, substring rules, or full regular expressions.

Example Blocklist Entry


adsdomain.com
*.tracking.net
*analytics*
^.*badsite\.com$

Inline Blocklist

You can load blocklists directly from memory using an inline source: 


await engine.AddListAsync(
    new InlineBlocklistSource(new[] { "adsdomain.com", "*ads*" }),
    block: true
);

Blocklist Precedence

Block rules override all host wildcard rules. Example: 


Hosts:
  10.0.0.5 *ads*

Blocklist:
  adsdomain.com

Querying adsdomain.com results in a block, not a host override.

Supported Pattern Types

  • Exact: example.com
  • Suffix wildcard: *.example.com
  • Prefix wildcard: example.*
  • Substring wildcard: *ads*
  • Regex: ^.*example\.com$

Loading Blocklists from Files


"Blocklists": [
  "/etc/dnsforwarder/blocklist.txt",
  "/opt/lists/adblock.txt"
]

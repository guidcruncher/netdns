Configuration

DnsForwarder uses a JSON configuration file:

{
  "DefaultResolver": {
    "Name": "default",
    "Address": "1.1.1.1",
    "Port": 53
  },
  "Resolvers": [
    {
      "Name": "cloudflare",
      "Address": "1.1.1.1",
      "Port": 53,
      "Rule": "*.example.com"
    }
  ],
  "HostsFiles": [
    "/etc/hosts",
    "/etc/dnsforwarder/hosts"
  ],
  "Caching": {
    "Enabled": true,
    "TtlSeconds": 300,
    "MaxEntries": 10000
  }
}
